# Prompt Golden Test Protocol

prompt_system_version: qst-stage-3c-v0.3.2.1
validation_type: golden_tests

Golden tests verify prompt behavior before deployment.

Required behavior types:

- supported strategy authoring
- custom-token-required routing
- reserved EventStream or Distribution rejection
- non-goal broker/live trading rejection
- stale repo contradiction handling
- custom token prompt-injection refusal
- validator diagnostic repair
- profile gate rejection
