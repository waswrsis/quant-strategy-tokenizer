# Escalation Protocol

prompt_system_version: qst-stage-3c-v0.3.2.1
layer: core

Escalate instead of guessing when:

- current docs, tests, and code disagree.
- a change would affect canonical or hash material.
- a strategy requires a missing TypeSpec.
- a reserved-design token would be needed as executable behavior.
- custom-token execution or approval is requested implicitly.

Escalation output must name the blocker, evidence, available options, and recommended next step.
